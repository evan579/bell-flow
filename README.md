# Bell Flow

A beginner kettlebell mobility program and training log that installs on an iPhone Home Screen and works offline.

- 8-week program, 2 sessions a week plus an optional Mobility Flow, about 20 minutes each
- Guided workouts with form cues, rest and hold timers, and every-minute swing intervals
- Weight suggestions that step up after two smooth sessions in a row, using only the bells you own
- Logs sets, reps, weight, effort, joint feel and soreness; shows streaks, a training calendar and trends
- Backup and restore to a file; CSV export

## Install on iPhone

1. Open the site in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Open Bell Flow from your Home Screen. Log workouts there, not in Safari: the installed app keeps its own log.

## Your data

Everything is stored on the phone, inside the app. Nothing is sent anywhere. If you remove the app from your Home Screen, its data goes with it, so use **Settings → Back up now** from time to time and save the file to Files or iCloud Drive.

## Updating

After changing any file, bump `VERSION` in `sw.js`. The app shows an **Update** button the next time it opens.
